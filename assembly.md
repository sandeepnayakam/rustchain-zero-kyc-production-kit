## Mechanical reference render (optional)

Per-section segment: still + wav → mp4 (720p or 1080p), then concat:

```bash
ffmpeg -y -loop 1 -i visuals/sec-01.png -i voiceover/sec-01.wav -t <sec_dur+1.0> \
  -vf "scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2:color=black,format=yuv420p" \
  -c:v libx264 -crf 20 -preset veryfast -r 30 -c:a aac -b:a 192k -shortest seg-01.mp4
# ...repeat per section, then:
ffmpeg -y -f concat -safe 0 -i list.txt -c copy -movflags +faststart reference-render.mp4
```
